# ✨ Chascuro 🌙

An experimental, mobile-first Bitcoin ecash wallet PWA that can connect to multiple Fedimint federations. Chascuro presents a combined balance and routes each incoming Lightning invoice to one connected federation based on its balances. Outgoing Lightning payments normally use one federation that can cover the complete payment; cross-federation partial MPP is not implemented. A development-only two-federation consolidation spike is available for tiny manual tests. It also includes Marmot chat integration. Working on this for fun to explore UI design and become more familiar with the [Marmot protocol](https://github.com/marmot-protocol/marmot). All code is generated by AI.

## Warning

Do **not** use Chascuro in production or with real funds. Wallet recovery has not been proven yet. If you run it, use only with an extremely small amount of test funds you are prepared to lose. I make no guarantee that this application is secure.

## Start locally

Use Node 24 LTS, then:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. For a deterministic simulated wallet, run
`npm run dev:fake` instead.

For the development-only combined-balance Lightning spike, run:

```sh
npm run dev:consolidation-test
```

It requires exactly two same-network Lightning federations. The primary
federation is the payment sink and the other federation is the source. When the
primary cannot pay an invoice of at most 1,000 sats, the wallet may make one
ordinary Lightning transfer into it and then pay the merchant. Keep the app
open for the complete operation. This spike has no automatic reload recovery,
retry, reversal, or Activity grouping and must not be used with meaningful
funds.

## Build it
