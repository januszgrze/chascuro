# ✨ Chascuro 🌙

An experimental, mobile-first Bitcoin ecash wallet PWA that can connect to multiple Fedimint federations. Chascuro presents a combined balance and routes each incoming Lightning invoice to one connected federation based on its balances. Outgoing Lightning payments currently use one federation that can cover the complete payment; cross-federation partial MPP is not implemented. It also includes Marmot chat integration. Working on this for fun to explore UI design and become more familiar with the [Marmot protocol](https://github.com/marmot-protocol/marmot). All code is generated by AI.

## Warning

Do **not** use Chascuro in production or with real funds. Wallet recovery has not been proven yet. If you run it, use only with an extremely small amount of test funds you are prepared to lose. I make no guarantee that this application is secure.

## Start locally

Use Node 24 LTS, then:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. For a deterministic simulated wallet, run
`npm run dev:fake` instead.

## Build it

```sh
npm run build
npm run preview
```

For the technical security boundary and how to report a vulnerability, see the [threat model](THREAT_MODEL.md) and [security policy](SECURITY.md).
